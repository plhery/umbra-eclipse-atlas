# Security policy

## Reporting a vulnerability

Please do not open a public issue for a security vulnerability. Use GitHub’s private [security advisory form](https://github.com/plhery/umbra-eclipse-atlas/security/advisories/new) and include:

- the affected URL or component;
- clear reproduction steps;
- the likely impact;
- any suggested mitigation.

Reports about the current `main` branch and the live site are in scope. You will receive an acknowledgement as soon as the report has been reviewed.

For incorrect eclipse predictions or other scientific accuracy concerns that do not expose users or systems, use a regular bug report instead.
